# digital-clock-python
A simple digital clock built using Python and Tkinter. I made this project while learning GUI programming and working with Python libraries. The clock updates every second and displays the current time in a clean interface.

One more project while learning Python.

This is a simple digital clock made using Python and Tkinter. I built it to understand how GUI applications work instead of only making console projects.

## Features

- Live digital clock
- Updates every second
- Clean and simple interface

## Tech Used

- Python
- Tkinter

## Learned While Building

- Basic GUI in Python
- Tkinter Labels
- Time module
- `after()` function for live updates
